## About This Course

This is the official courseware repository for the WSQ **Certified Lean Six Sigma Yellow Belt (CLSSYB) Training** (TGS-2025053922), delivered by [Tertiary Infotech Academy Pte Ltd](https://www.tertiarycourses.com.sg/).

The course follows the **DMAIC roadmap** end to end — Define, Measure, Analyze, Improve, Control — across **14 hands-on labs** (9 core and 5 elective). It is grounded in the Council for Six Sigma Certification (CSSC) Yellow Belt body of knowledge, so what you learn matches the recognised Yellow Belt standard.

It is written for people who support improvement work rather than lead it — analysts, executives, engineers, supervisors and team leads who want to read process data properly, find a root cause and make a change that holds.

## Learning Outcomes

| # | On completion, you will be able to |
|---|------------------------------------|
| **LO1** | Define a project and establish the scope of work using Six Sigma's Define, Measure and Analyse phases. |
| **LO2** | Apply Lean and Six Sigma concepts — value, waste, defects and variation — to a work process. |
| **LO3** | Map a process using SIPOC, process maps and value stream maps to expose handoffs and waste. |
| **LO4** | Collect and analyse process data using check sheets, Pareto charts, run charts and basic metrics. |
| **LO5** | Identify root causes using 5 Whys, Fishbone analysis and evidence-based prioritisation. |
| **LO6** | Recommend improvement and control actions to sustain gains, and prepare for certification. |

## The Activity Data Set

Every activity works from one continuous scenario — the **Contoso Service Desk** — and one shared set of numbers, so your lab outputs accumulate into a single improvement package.

| Yield | 76% |

These are the same figures as the Case Study assessment, so activity work doubles as revision. Headline values: [activities/scenario-key-figures.csv](activities/scenario-key-figures.csv).

## How to use

1. Read the Learner Guide first — it follows the same DMAIC order as the course.
2. Work the core activities in order using the Contoso Service Desk scenario.
3. Complete the elective activities if time allows, or as post-course practice.
4. Keep every worksheet — the final activity combines them into one improvement package.
5. Review the Checklist at the end of each activity before moving on.

## Repository structure

```
courseware/          slide deck (PPTX + PDF), Learner Guide, Lesson Plan
  archive/           superseded deck versions
  assets/            diagrams and images used by the deck
activities/          one self-contained folder per activity:
  NN - <Name>/       ANN-Facilitator-Guide-*.docx|pdf
                     ANN-Learner-Worksheet-*.docx|pdf
                     ANN-Checklist-*.docx|pdf
                     data/      the mock CSV data to analyse
                     templates/ blank CSV worksheets to complete
  scenario-key-figures.csv   the headline metrics all activities share
  tools.md           the interactive toolkit
archive/             superseded material (the previous labs/ layout)
LG-Certified Lean Six Sigma Yellow Belt (CLSSYB) Training.md
                     Learner Guide (Markdown mirror of the DOCX)
.claude/skills/courseware-build/build/
                     single-source generators: one content module
                     drives the deck, LP, LG and labs
```

All artifacts are generated from `course_data.py` + `data_domainN.py`, so the deck, Lesson Plan, Learner Guide and labs stay 100% aligned.
